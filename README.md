# Retail Sales Forecasting System

## Project Overview
This project predicts future retail sales using machine learning models and exposes results via a Flask API.

## Models Used
- SARIMA
- Prophet
- XGBoost
- LSTM

## How to Run

### Run model:
python main.py

### Run API:
python app.py

Open:
http://127.0.0.1:5000/predict/Texas
